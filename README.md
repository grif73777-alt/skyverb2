# Skyverb

Реверб + эмулятор низкого битрейта (lossy-кодек) в формате **VST3**. Минималистичный белый интерфейс, тёмные ползунки.

## Как получить готовый .vst3 (Windows, без установки компиляторов)

1. Создайте аккаунт на github.com (если нет) и новый репозиторий, например `skyverb` (можно приватный).
2. Загрузите в него **всё содержимое этой папки** (кнопка *Add file → Upload files*; папку `.github` тоже, она скрытая — проще перетащить всё целиком или использовать GitHub Desktop).
3. Откройте вкладку **Actions**. Сборка запустится сама (или нажмите *Build Skyverb VST3 (Windows)* → *Run workflow*). Первый раз она идёт около 10–15 минут.
4. Когда появится зелёная галочка, откройте запуск и внизу в разделе **Artifacts** скачайте `Skyverb-VST3-Windows`.
5. Распакуйте архив. Внутри папка `Skyverb.vst3`. Скопируйте её целиком сюда:
   `C:\Program Files\Common Files\VST3\`
6. FL Studio: **Options → Manage plugins → Find installed plugins** (с включённым *Verify plugins*). Skyverb появится в списке эффектов. Добавьте его на канал микшера.

Если сборка красная, откройте её лог, скопируйте последние 30–40 строк ошибки и пришлите мне.

## Параметры

**Reverb**

| Параметр | Что делает |
|---|---|
| Size | размер помещения (длины линий задержки, плотность и «масштаб» звука) |
| Decay | время затухания RT60, 0.1–30 с |
| Pre-delay | задержка перед ревербом, 0–250 мс |
| Damping | поглощение верхов в хвосте (0 = светлый хвост, 100 = тёмный) |
| Diffusion | плотность ранних отражений на входе |
| Modulation | лёгкая модуляция задержек: убирает металлический звон на длинных хвостах |
| Low cut / High cut | фильтры на реверберированный сигнал |
| Width | ширина стерео хвоста (0 = моно, 100 = как есть, до 150) |

**Lossy**: алгоритм работает как настоящий кодек: MDCT (512 бинов), joint-stereo (M/S), полосы по шкале Барк, степенное квантование x^0.75 как в MP3/AAC, подбор шага под бюджет бит выбранного битрейта и срез верхов, зависящий от битрейта.

| Параметр | Что делает |
|---|---|
| Bitrate | 8–192 kbps. Чем ниже, тем больше «дыр» в спектре, пре-эхо, булькающие верха и срез частот |
| Amount | смесь обработанного и необработанного сигнала (0 = выкл.) |
| Apply to | **WET ONLY** — кодек обрабатывает только реверб, **ALL** — весь выходной сигнал |

**Master**: Mix (равномощный dry/wet) и Output (-24…+12 dB).

## Задержка (latency)

Кодеку нужно 1024 сэмпла (≈23 мс при 44.1 кГц). Плагин сообщает это FL Studio, и она сама компенсирует задержку (PDC). Значение постоянное и не зависит от Amount, поэтому ничего не «плывёт» при автоматизации.

## Проверка алгоритмов (опционально)

В папке `tests` лежат тесты DSP без JUCE:

```
cd tests
g++ -std=c++17 -O2 -I../Source/dsp dsp_tests.cpp -o dsp_tests && ./dsp_tests
```

Проверяются: FFT и MDCT (точное восстановление сигнала), задержка кодека, срез полосы по битрейту, измеренное время затухания ревера против ручки Decay, действие Damping, стабильность при случайных скачках параметров на 44.1 и 96 кГц.

`render_demo.cpp` собирает короткое демо (сухой звук, реверб, реверб + lossy 64 / 24 / 10 kbps) в WAV.

## Структура

```
Source/dsp/        Fft.h, Mdct.h, LossyCodec.h, Reverb.h   (чистый C++, без JUCE)
Source/            PluginProcessor, PluginEditor, SkyLookAndFeel
CMakeLists.txt     сборка (JUCE 8.0.4 скачивается автоматически)
.github/workflows  облачная сборка под Windows
tests/             тесты и демо
```

## Лицензия JUCE

JUCE распространяется по AGPLv3 или по коммерческой лицензии. Если вы публикуете плагин, нужно либо открыть его исходники под AGPL, либо купить/оформить лицензию JUCE. Для личного использования это не важно.
